---

## 用户输入
需要从用户输入中识别两个关键参数: 文章名称和文章归类（默认归为'博客'）。

其中文章归类是_posts文件夹下各文件夹的名称， 如果用户给的归类在_posts中不存在， 需要向用户确认后再继续执行。
## 命令调用
使用`npm run new`命令创建一个新博客, 参数为`${归类}/${文章名}`

## 示例
比如如下输入:
```input
帮我创建【大语言模型原理解析】文章
```
执行
```
npm run new 博客/大语言模型原理解析
```

如果以下输入:
```input
帮我创建Haskell的新文章: Monad
```
执行
```
npm run new Haskell/Monad
```
